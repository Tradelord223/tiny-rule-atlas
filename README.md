# Tiny Rule Atlas · Laboratory Edition

**How much can eight bits of law make?**

A browsable, reproducible atlas of elementary cellular automata: **256 rules ×
8 starting patterns × 2 boundary conditions = 4,096 experiments**. Each run
contains the complete space-time diagram, measurements, a trajectory hash,
and the result of a one-cell perturbation.

[Open the atlas](https://tradelord223.github.io/tiny-rule-atlas/)
· [Experiment in the laboratory](https://tradelord223.github.io/tiny-rule-atlas/laboratory.html)
· [Read the field guide](https://tradelord223.github.io/tiny-rule-atlas/field-guide.html)

Simple local rules can generate structure that is difficult to predict by
looking at the rule alone. This project makes that gap inspectable: change a
rule, starting pattern, or boundary, then compare the actual recorded results.
It is a finite experiment collection and teaching tool, not a new
classification of cellular automata.

## New in 0.2.0

The Laboratory Edition turns an observation into a reproducible investigation.

- **Compare two systems.** Choose separate rules, starting states, and boundaries;
  run 64, 128, or 256 cells for up to 1,024 updates. Scrub through time and compare
  the original, perturbed, and difference diagrams.
- **Test a counterfactual.** Edit the initial state, toggle one cell, and follow
  the difference over time. Density, activity, damage, and recurrence each answer
  a different question.
- **Study traffic flow.** Rule 184 conserves cars on a ring. Change the car count,
  measure motion, and compare finite-run flow with the model's asymptotic
  `min(density, 1 - density)` relationship. The units are cells and updates;
  this is not a calibrated prediction for a real road.
- **Take the result with you.** Export high-resolution trajectory PNGs,
  measurement-series CSVs, and complete session JSON. Share a configured experiment
  with a link.
- **Follow six guided investigations.** The field guide includes hypotheses,
  controlled comparisons, interpretation limits, primary sources, and a classroom
  sequence. Photorealistic editorial illustrations add context and are labeled
  separately from measured or simulated evidence.

The original 4,096-record corpus is unchanged. Laboratory runs are calculated
in your browser; they do not silently replace the published reference data.
See [release notes](CHANGELOG.md) and the [laboratory methods](docs/laboratory-methods.md).

## Explore locally

Serving locally requires Python 3.11 or newer. There are no third-party Python
dependencies, JavaScript packages, build steps, accounts, or API keys. You can
also use the public site without running any local environment.

```sh
git clone https://github.com/Tradelord223/tiny-rule-atlas.git
cd tiny-rule-atlas
python3 -m http.server 8000 --bind 127.0.0.1
```

Open <http://127.0.0.1:8000>. Use the rule controls, starting-pattern selector,
and boundary selector; a URL fragment preserves the selected experiment.
The catalog lets you compare experiments without loading thousands of DOM
elements at once. The explorer fetches recorded data; it does not need a
backend. Visit `/laboratory.html` to calculate new runs or `/field-guide.html`
for the guided investigations. Node.js 20 or newer is needed only to run the
additional laboratory engine tests below.

## Inspect and reproduce

```sh
# Inspect a fresh calculation of one experiment.
python3 atlas.py inspect --rule 30 --seed single --boundary wrap

# Check the implementation against known rules and an independent scalar model.
python3 -m unittest discover -s tests -v

# Verify the browser laboratory against the complete reference corpus,
# one-cell counterfactuals, and traffic conservation/flow relationships.
node --test tests/lab-core.test.mjs

# Check each page's links, assets, section anchors, and element IDs.
python3 scripts/check_site.py

# Recalculate and verify the complete committed corpus and its index.
python3 atlas.py verify

# Rebuild the corpus explicitly, or check without writing files.
python3 scripts/build_dataset.py
python3 scripts/build_dataset.py --check
```

Every experiment stores 128 cells through 128 updates, including generation
zero for 129 rows total. Leftmost cells occupy the most significant bits of
the packed hexadecimal rows. The [data contract](docs/data-contract.md)
defines every seed, metric, bit, and boundary convention.

Trajectories are deterministic. The compression measurement uses zlib; its
bytes may differ between compressor versions. Generator environment details
are recorded separately in `data/provenance.json`. See the methodology for
the exact scope of reproducibility and each metric's limits.

## Provenance

This project was built with OpenAI Codex. The corpus is generated by the
included simulator and published as a single dataset. Every record identifies
its experimental inputs and trajectory hash. Some rules converge to identical
behavior; distinct parameter combinations need not produce distinct patterns
or discoveries. The photorealistic editorial images are AI-generated
illustrations, not photographs of measured specimens or records of an actual
traffic experiment. Their exact prompts and intended uses are documented in
[visual asset provenance](docs/visual-assets.md).

## Layout

| Path | Purpose |
| --- | --- |
| `atlas.py` | Simulator, measurements, verifier, and command-line interface |
| `data/experiments/rNNN/` | Complete experiment records, grouped by rule |
| `data/catalog.json` | Browser index and per-experiment summaries |
| `data/provenance.json` | Generator environment information |
| `index.html`, `assets/` | Static interactive explorer |
| `laboratory.html`, `assets/lab-core.mjs` | Browser experiment engine and comparative laboratory |
| `field-guide.html` | Guided investigations, primary sources, and teaching sequence |
| `tests/` | Independent implementation and regression checks |
| `docs/` | Definitions, limitations, and primary references |
