# Changelog

## 0.2.0 · Laboratory Edition

The atlas now supports controlled comparisons and new calculations in the
browser, alongside the unchanged reference corpus.

- Added a comparative laboratory with separate rules, seeds, and boundaries;
  selectable lattice width and duration; custom initial states; one-cell
  perturbations; difference diagrams; generation scrubbing and playback.
- Added per-generation measurements and PNG, CSV, and session JSON exports.
- Added an exact-count Rule 184 traffic experiment and a fundamental diagram
  comparing observed flow with the deterministic model's asymptotic prediction.
- Added six sourced investigations, model interpretation guidance, and a
  classroom sequence in a dedicated field guide.
- Added two photorealistic editorial illustrations with explicit provenance.
  Simulation diagrams continue to display actual computed cells.
- Added an independent JavaScript laboratory test suite, including parity with
  every reference trajectory, perturbation checks, and traffic conservation.
- Repaired the publisher link to Cook's Rule 110 universality paper.

The 4,096 canonical experiment records, their hashes, and their Python generator
retain the initial edition's format and results.

## Initial atlas

- Published all 256 elementary rules across eight named seeds and two boundary
  conditions, with full trajectories, metrics, cycle detection, and hashes.
- Added the deterministic Python simulator, data verifier, independent scalar
  tests, static explorer, and scientific documentation.
